Авторизация

1. Какие данные мы обрабатываем

  • номер телефона клиента для входа и идентификации;
  • одноразовый код подтверждения для проверки входа;
  • данные бонусного счёта, истории чеков, видов топлива, суммы трат и QR-кода клиента;
  • необязательные данные профиля: имя, фамилия, отчество, дата рождения, фотография;
  • технические данные устройства и браузера, необходимые для безопасной работы веб-приложения и офлайн-кеша.

2. Для чего используются данные

  • для входа клиента в мобильную часть программы лояльности;
  • для показа бонусного баланса, истории операций и чеков;
  • для начисления и списания бонусов на кассе по QR-коду клиента;
  • для отображения персональных условий, новостей и сроков сгорания бонусов;
  • для восстановления данных при нестабильном интернете и повышения устойчивости мобильной части.

3. Какие данные могут храниться на устройстве

Для ускорения работы и корректного отображения приложения при слабом интернете мобильная часть может временно сохранять в браузере локальный кеш: язык интерфейса, последние загруженные данные профиля, новости, историю операций, QR-код и другие служебные данные. Эти данные используются только для работы АЗС Бонус в браузере пользователя.

4. Хранение, защита и передача

Данные клиента обрабатываются серверной частью АЗС Бонус и не предназначены для публичного доступа. Передача информации между приложением и сервером должна осуществляться только по защищённому HTTPS-соединению. Если используется внешний SMS-провайдер, номер телефона передаётся только в объёме, необходимом для доставки одноразового кода подтверждения.

5. Сроки хранения

Данные аккаунта и операций программы лояльности хранятся в течение срока работы аккаунта или до момента удаления по запросу пользователя, если иное не требуется для бухгалтерского, налогового или иного обязательного учёта. Локальный кеш на устройстве может быть очищен пользователем в настройках браузера или автоматически обновлён приложением.

6. Права пользователя

Пользователь может запросить обновление, исправление или удаление персональных данных, а также задать вопрос по обработке данных, написав на remix_993@mail.ru или обратившись к оператору программы лояльности. Запросы рассматриваются в разумный срок в соответствии с применимыми правилами обслуживания и законодательством.

7. Ограничения и детские данные

Приложение не предназначено для самостоятельного использования детьми без участия законных представителей. Если выяснится, что данные были предоставлены с нарушением этого правила, владелец сервиса вправе удалить такие данные после проверки обращения.
